# Shreyash Malkar — Portfolio Website

A responsive static portfolio website built with plain HTML, CSS and JavaScript. It includes the two advertising images supplied for the portfolio.

## Project structure

```text
shreyash-portfolio-website/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── images/
        ├── bourbon-ad.jpg
        └── sprite-ad.png
```

## Preview locally

1. Extract this ZIP.
2. Open `index.html` in a web browser.
3. For a more realistic local development preview, open the folder in VS Code and use the Live Server extension (optional).

## Publish for free with GitHub Pages

1. Sign in to GitHub and create a **public** repository (for example, `shreyash-portfolio`).
2. Upload **all files and folders inside this project** to the repository root. Make sure `index.html` is at the root, not inside an extra nested folder.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment source, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The Pages panel will show the website URL.

## Personalise before publishing

- Update the name, biography, email and phone in `index.html` if needed.
- Add only tools, skills, social links and work experience that accurately describe you.
- The two brand-themed designs are labelled as personal advertising concepts; keep that note unless they were official commissioned work.
- If you later add UI/UX projects or AI films, add new project cards with images or video links.
- Google Fonts requires an internet connection; the site still works with fallback fonts if they are unavailable.

## Files

- `index.html` — content and page structure
- `style.css` — colours, responsive layout, spacing and visual styling
- `script.js` — mobile navigation, reveal animations and current footer year
- `assets/images/` — portfolio images
